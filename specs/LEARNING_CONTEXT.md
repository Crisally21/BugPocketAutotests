КОНТРАКТ API, ПРОВЕРЕННЫЙ 09.10.2026

Баги:
GET   /api/bugs
GET   /api/bugs/{id}
POST  /api/bugs                  → 201, Location
PUT   /api/bugs/{id}             → 200, сохраняет status
PATCH /api/bugs/{id}/status      → 200

Фильтры списка: priority и status.
Приоритеты: LOW, MEDIUM, HIGH.
Статусы: NEW, IN_PROGRESS, FIXED.
Новый баг получает NEW.
header обязателен, максимум 200 символов.
priority обязателен.
Сервер удаляет пробелы по краям header.
DELETE бага в текущем API нет.

Вложения:
GET    /api/bugs/{bugId}/attachments
POST   /api/bugs/{bugId}/attachments
GET    /api/bugs/{bugId}/attachments/{attachmentId}/content
GET    /api/bugs/{bugId}/attachments/{attachmentId}/download
DELETE /api/bugs/{bugId}/attachments/{attachmentId}

Загрузка: multipart, имя поля files, HTTP 200.
Удаление: HTTP 204.
Список: JSON-массив.
Путь с attachmentId без /content или /download
не является GET списка.
Используй пути без завершающего слеша.

Ответ загрузки:
{
  "accepted": [
    {
      "id": 1,
      "originalFilename": "screenshot.png",
      "mediaKind": "IMAGE",
      "fileType": "PNG",
      "contentType": "image/png",
      "sizeBytes": 123,
      "createdAt": "..."
    }
  ],
  "errors": [
    {
      "filename": "unsupported.csv",
      "message": "..."
    }
  ]
}

Поддерживаются:
- PNG, JPG, JPEG.
- MP4, MOV, MKV, AVI, WEBM.
- TXT, LOG, PDF.

Ограничения:
- Один файл и суммарный размер вложений бага:
  максимум 25 000 000 байт.
- Отдельного лимита количества нет.
- Пустые файлы отклоняются.
- Тип определяется по расширению.
- Изображения проверяются чтением содержимого.
- PDF проверяется по заголовку %PDF-.
- TXT/LOG не проверяются на кодировку.
- Ошибка генерации видеопревью отклоняет видео.
- При смешанном пакете допустимые файлы сохраняются,
  если помещаются в оставшуюся квоту.
- При превышении квоты вся допустимая часть пакета отклоняется.
- Не фиксируй точное сообщение для неизвестного расширения:
  оно сейчас берётся из исключения Java.
- errors.header относится к валидации бага,
  не добавляй такую проверку к произвольному 404.
